# Atividade da aula 5 - Descrição das ações no GitHub
_A atividade da aula 5 descreveu algumas funções do GitHub, como repositórios, branches e commits, e mostrou como organizar o projeto com issues, milestones e project._
# Criação do repositório
O repositório é o local onde o projeto fica armazenado, contendo os arquivos, códigos, histórico de alterações e comentários.

<p align="center"><img width="600" height="600" alt="Image" src="https://github.com/user-attachments/assets/f8cadb12-dfff-4a4c-b80d-f1b28ed25e90" />

# Clone do repositório
O clone é a cópia de um repositório remoto para o computador local, permitindo que o desenvolvedor trabalhe no projeto.

<p align="center"><img width= "600" height="600" alt="open-with-desktop" src="https://github.com/user-attachments/assets/b49c68bd-7210-41ab-bf33-e708c49b49f2" />

# Criação de branch
A branch é uma ramificação do projeto usada para desenvolver novas funcionalidades ou testar mudanças sem alterar a versão principal.

<p align="center"><img width="600" height="600" alt="file-tree-view-branch-dropdown-expanded" src="https://github.com/user-attachments/assets/9f98bf52-66b8-4c9d-ac46-c97f41290023" />

# Registro de commits
O commit registra e salva as alterações feitas nos arquivos do projeto, mantendo um histórico das modificações.

<p align="center"><img width="600" height="600" alt="branch-history-commit" src="https://github.com/user-attachments/assets/a642283b-0b84-442c-a575-145e7a67e58a" />

# Envio das alterações (push)
O push envia as alterações feitas no repositório local para o repositório remoto.

<p align="center"><img width="600" height="600" alt="select-branch-from-dropdown" src="https://github.com/user-attachments/assets/41386bb2-9a77-4658-8c54-15bb5c603412" />

# Atualização do repositório local (pull)
O pull atualiza o repositório local com as mudanças que foram feitas no repositório remoto.
