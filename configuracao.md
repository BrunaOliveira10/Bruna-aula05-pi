Na aula do dia 24 de março a aula teve como objetivo aprender a configuração do ambiente

Esse é o passo a passo das configurações do ambiente:

Antes de migrar para o editor de texto será necessário utilizar o *terminal da Windows(PowerShell)*

Para criar a pasta use o comando; *mkdir django_aulas*

Depois; *cd django_aula*

Ativar; *venv\Script\activate*

Na próxima etapa instalar django; *pip install django*

Criar Projeto; *django-admin startproject meu projeto*

Abrir o editor; *cod meu projeto*

E por ultimo o comando; *cod.*

Ele abrira automaticamente o VS Code.
